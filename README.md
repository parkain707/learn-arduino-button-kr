## ✨ 핵심 기능 및 구현 세부사항

### 1. 3D WebGL 실시간 인터랙션
* **Three.js 프로시저럴 모델링:** 아두이노 Uno R3 기판, 하프 사이즈 브레드보드, 12mm 4핀 택트 스위치, 10kΩ 풀다운 저항(갈-검-주-금), 220Ω LED 보호 저항(빨-빨-갈-금), 5mm 적색 확산형 LED, 색상별 커브 3D 점퍼 전선.
* **물리 클릭 애니메이션:** 마우스로 3D 버튼을 클릭하거나 누르고 있으면 90ms 동안 3차 감속 곡선(Cubic Out Easing)으로 버튼 캡이 `1.3mm` 아래로 쏙 들어가며, 마우스를 떼면 부드럽게 원래 위치로 복귀합니다.
* **카메라 제어:** 마우스 드래그로 360도 궤도 회전(Orbit), 마우스 휠 줌(Zoom), 우클릭 패닝(Pan), 시점 초기화(R 단축키).

### 2. 완벽한 아두이노 시뮬레이션 엔진
* **Hold (누르고 있기) 모드:** 버튼을 누르고 있는 동안에만 D2 핀이 HIGH가 되어 13번 핀에 연결된 LED와 Uno 기판 내장 'L' LED가 점등됩니다.
* **Toggle (토글 전환) 모드:** 버튼을 누르는 순간(Rising Edge)을 감지하여 누를 때마다 LED가 켜지고 꺼집니다. 30ms 소프트웨어 디바운스(Debounce) 로직이 반영되어 있습니다.
* **코드 트레이싱 (Trace Highlighting):** 가상 스케치 실행 시 현재 실행되는 C++ 아두이노 코드 라인이 실시간으로 강조 표시됩니다.
* **시리얼 모니터 (Serial Monitor):** 보드 스케치 업로드 과정 및 실시간 핀 전압 상태(`D2 → HIGH (눌림)`, `D2 → LOW (해제)`)가 터미널 로그로 기록됩니다.

### 3. 직관적인 교육용 인터페이스 (한국어 현지화)
* **3D 앵커 콜아웃 (Callouts):** 3D 공간상의 부품 위치를 2D 화면 좌표계로 실시간 투영하여 부품별 명칭과 역할을 표시.
* **4대 상세 탭 메뉴:**
  * **개요 (Overview):** 디지털 입력의 기본 개념과 플로팅(Floating) 현상, 풀다운 저항의 필요성 해설.
  * **핀 연결 (Pinout):** 5V, D2, GND, D13 전선 결선표.
  * **코드 설명 (Example):** `pinMode(BUTTON, INPUT)`, `digitalRead()`, 모드별 동작 원리.
  * **상세 규격 (Specifications):** 스위치 규격, 임계 전압 레벨, 바운스 타임, `INPUT_PULLUP` 팁.

## 🧒 초등학생 눈높이 모드 (`kids.html`) 특별 기능
1. **친근한 팅커봇 로봇 캐릭터:** 어려운 전문 용어 대신 일상 속 사물로 원리를 설명합니다.
   * **버튼(스위치):** 징검다리 다리 놓기
   * **풀다운 저항:** 전기가 얌전히 내려가는 안전 미끄럼틀
   * **아두이노 Uno:** 생각을 담당하는 똑똑한 꼬마 컴퓨터 뇌
2. **청각적 상호작용 (Web Audio API):** 마우스로 버튼을 누르고 뗄 때 실제 스위치 같은 경쾌한 "딸깍! 퐁!" 효과음이 재생됩니다.
3. **직관적인 모드 체험:**
   * 🛎️ **초인종 모드 (누를 때만 켜짐)**
   * 💡 **방 전등 스위치 모드 (누를 때마다 껐다 켜짐)**
4. **한눈에 쏙 들어오는 블록 설명:** C++ 코드를 엔트리/스크래치 형태의 말풍선 카드로 알기 쉽게 풀이합니다.

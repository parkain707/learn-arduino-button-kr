버튼 누르기 (Push a button)

스위치 입력과 10kΩ 풀다운 저항의 물리적 원리를 배우고, 아두이노 스케치 코드가 실시간으로 신호를 감지해 LED를 켜는 과정을 관찰합니다.

동작 원리 및 단계별 실습 순서:

  1. 우측 아래 [실행하기] 버튼을 눌러 코드를 아두이노로 전송합니다.
  2. 3D 화면의 빨간색 버튼을 마우스로 누르면 D2 핀에 5V가 공급됩니다.
  3. 전선을 타고 흐르는 황금빛 전기 파티클과 함께 LED가 점등됩니다.
5V버튼 좌측5V 전원 공급 (적색 전선)
D2버튼 우측 + 10kΩ디지털 입력 신호선 (청색 전선)
GND10kΩ 저항 반대편0V 풀다운 접지선 (네이비 전선)
D13220Ω → LED출력 신호선 (주황색 전선)
  • pinMode(BUTTON, INPUT): 2번 핀을 전압 감지 입력으로 설정합니다.
  • digitalRead(BUTTON): 버튼이 닫히면 HIGH(1), 열리면 LOW(0)을 읽습니다.
  • 코드 라인 추적: 버튼을 누르면 해당 C++ 코드가 노란색으로 하이라이트됩니다!

풀다운 저항을 뽑으면 어떻게 될까요?

화면 좌측 하단의 [👻 풀다운 저항 뽑기] 버튼을 눌러보세요. 저항이 빠지는 순간 버튼을 누르지 않아도 공기 중 정전기 노이즈로 핀이 진동하는 플로팅(Floating) 현상을 직접 목격할 수 있습니다!
